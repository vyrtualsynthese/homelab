# Audit — Traefik, 2026-11-21

> **Kind:** snapshot (2026-11-21) — a historical snapshot, not maintained. Findings are fixed by
> plans, never by editing this file.
>
> **In one line.** A read of the Traefik install the day its ownership moved from the K3s addon to
> `cluster/infrastructure/traefik/values.yaml`, taken before the v3 upgrade, to establish what was
> stable and what only looked stable.

## How it was read

- Cluster objects: the read-only `opencode-mcp` ServiceAccount (no write path was used).
- Metrics and series: the Prometheus HTTP API through Grafana's datasource proxy
  (`/api/datasources/proxy/uid/PBFA97CFB590B2093`), with `GRAFANA_TOKEN`.
- Dashboards and alert rules: the Grafana HTTP API on `https://grafana.kub.local`.
- Routes at rest: `cluster/` in the repository, at `develop` as of `82261b39`.
- The exposure rule: `hack/check-exposure.sh`, which passed over 72 routes.
- The chart under test: `/tmp/traefik-25.0.3/traefik`, the upstream 25.0.3 that K3s repackaged as
  `25.0.3+up25.0.0`.
