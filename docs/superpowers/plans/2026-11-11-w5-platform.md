# W5 — Platform Upgrades Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the cluster from K3s 1.30.1 and Traefik 2.9.4 to K3s 1.36.x and Traefik v3, through a rehearsed procedure, with the same ACME certificate and no unplanned ingress outage.

**Architecture:** Traefik leaves the K3s bundled addon and becomes an official-chart workload owned by this repo, first at 2.11 (which serves both CRD API groups, so routing never goes blind), then the CRDs are renamed to `traefik.io/v1alpha1`, then Traefik goes to v3. Only after that does K3s move, one minor at a time, servers one at a time. Every irreversible step is rehearsed first on a throwaway three-node cluster on `nas`.

**Tech Stack:** K3s (embedded etcd), Traefik official Helm chart, System Upgrade Controller, libvirt/cloud-init for the test cluster, argon2 for the dashboard.

**Spec:** `docs/superpowers/specs/2026-11-10-homelab-stabilisation-design.md` §9 W5

## Global Constraints

- **etcd quorum is two of three.** Never upgrade, reboot or restart two control-plane nodes at once. Order: `nuc0`, `rbp2`, `streaming`. `nas` is the agent and goes last.
- **Never let `channel: stable` run.** Every step sets an explicit version. The stable channel is currently `v1.36.5+k3s1`; `channel: stable` would jump straight there and skip five minors.
- **The ACME certificate must survive.** Reuse the existing `pvc-traefik-nfs` claim. Let's Encrypt allows five duplicate certificates per week and a re-issue wastes them.
- **Both CRD API groups are installed.** 2.11 reads `traefik.containo.us` and `traefik.io`; v3 reads only `traefik.io`. The rename therefore happens while on 2.11, never during or after the v3 step.
- Files under `cluster/argocd/**` are **CRLF**. Any bulk edit must preserve them.
- The builder has no cluster write access. Every cluster-side step is a runbook the operator executes, ending in a verification to paste back.
- **There is no backup.** W4 is deferred by decision. Take an etcd snapshot on a node before every production step and copy it off the node.

## Pre-flight facts to confirm, not assume

These come from `REBUILD.md` (verified 2026-10-23) and have not been re-checked since:

| Fact | Expected | If different |
|---|---|---|
| K3s version | `v1.30.1+k3s1` on all four nodes | adjust every version pin |
| SUC plans | `server-plan` and `agent-plan`, both pinned to `v1.30.1+k3s1` | do not start until they are pinned |
| Traefik | `rancher/mirrored-library-traefik:2.9.4`, Helm release `traefik`, chart 20.3.1 | the chart version drives the values schema |
| Live `HelmChartConfig` | `persistence.existingClaim: traefik` | the live value wins over the repo's |
| Actual mounted claim | `pvc-traefik-nfs`, 10Mi, NFS | this is the certificate store |
| IngressRoutes | 58 live objects, all `containo.us` | the rename count changes |
| `disable: [traefik]` | **absent** from `/etc/rancher/k3s/config.yaml` | if already present, Task 6 changes |

## Review Focus

1. **Two servers upgraded at once loses etcd quorum.** Task 10–12 have a strict order and a hard "stop after one node" rule.
2. **A re-issued certificate burns the weekly duplicate limit.** Task 6 verifies the certificate serial before and after; a changed serial means a re-issue and must be investigated, not accepted.
3. **v3 silently drops `traefik.containo.us` resources.** Task 7 fails the plan if any `containo.us` object remains; Task 8 refuses to run until that count is zero.
4. **A bulk grep-and-replace corrupts the CRLF files under `cluster/argocd/**`.** Task 7 uses a script that preserves line endings and verifies with `file`.
5. **The test cluster proves the wrong thing.** It must run the same chart *version* and the same values file as production, or the rehearsal is theatre. Task 5 pins both explicitly.

## Rollback summary

| Step | Rollback |
|---|---|
| K3s minor | Re-run the installer with the previous version on that node; one node at a time |
| etcd unquorate | `--cluster-reset` from the newest snapshot, per `docs/runbooks/restore-etcd.md` |
| Traefik v3 | `helm rollback traefik` to the 2.11 revision; 2.11 reads both API groups, so the renamed resources keep working |
| Addon | Remove `disable: [traefik]` from the node config and restart K3s; the bundled addon returns and takes the ports |
