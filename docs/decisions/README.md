# Decisions

One short record per decision that a future reader would otherwise have to reconstruct. The format
is the one the design already uses: the decision, who made it, and what it costs if it is wrong.

Start with `docs/superpowers/specs/2026-11-10-homelab-stabilisation-design.md` §7, which holds the
decisions taken during that design. Records here are for decisions made afterwards.

Template:

```markdown
# <decision>

Date:
Decided by:
Status: active | superseded by <link>

## The decision

## Why

## What it costs if it is wrong
```
