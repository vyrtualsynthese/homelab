# AshuLab brand assets

The mark for the homelab: three nodes joined in a triangle, the top one carried out into a
crossbar so the shape reads as the letter A. AshuLab is the platform; the services on it take
Ashu-prefixed names (AshuFlex, AshuCraft), and those get their version of the same mark by
swapping the accent colour.

Everything here is generated by `build.py`. Edit the geometry or the palette there and rebuild;
do not hand-edit the SVGs, because the next build overwrites them.

## Palette

| Name | Hex | Used for |
|---|---|---|
| Navy | `#0B1220` | badge disc; ink on light backgrounds |
| Cyan | `#2DD4FF` | the mark on the badge; accent on dark backgrounds |
| Deep cyan | `#0E7490` | accent on light backgrounds — the bright cyan fails contrast on white |
| Paper | `#E8EEF5` | wordmark on dark backgrounds |

## Files

| File | Use |
|---|---|
| `ashulab-badge.svg` | navy disc, full colour. Discord server icon, authentik login, server avatars |
| `ashulab-badge-transparent.svg` | the mark alone, no disc — for a dark UI that supplies its own backdrop |
| `ashulab-badge-mono-navy.svg` | one colour, for white or light backgrounds: README, docs, print |
| `ashulab-lockup-dark.svg` | badge plus "AshuLab" wordmark, for dark backgrounds |
| `ashulab-lockup-light.svg` | same, for light backgrounds |
| `png/` | exports at 512, 256, 128, 64 and 32 px; lockups at 1600 and 800 wide |
| `concepts/` | the exploration that led here, kept as the record of the decision |

Every PNG is rasterised from its SVG at the target size. None is upscaled from a smaller file.

## Where to use which

- **Discord server icon** — `ashulab-badge-512.png`. Discord crops avatars to a circle, and the
  disc already fills the square, so nothing is lost in the crop.
- **authentik login page** — `ashulab-lockup-dark-800.png`, or the SVG if the theme can take it.
  authentik's default theme is dark.
- **Favicons and app tiles** — the 32 and 64 px badges. The A stays readable at 32.
- **README, docs, anything on white** — `ashulab-badge-mono-navy` or `ashulab-lockup-light`.

## Rebuilding

Needs `cairosvg` (which needs the system Cairo library) and `Pillow`:

```bash
python3 -m venv .venv
.venv/bin/pip install cairosvg pillow
.venv/bin/python build.py
```

The build centres the mark by measurement, not by eye: it renders the ink, compares the bounding
box centre with the badge centre, and shifts the group until they agree. The run ends by printing
that comparison, which should read `(255.50, 255.50)` against `(256, 256)` — half a unit is
rasteriser rounding, not drift.

The lockups set their text in Ubuntu Sans. On a machine without it the SVG falls back to DejaVu
Sans and the wordmark will not match the exports; the PNGs are the definitive rendering, and the
SVG is meant to be opened where the font exists or converted to outlines before shipping.
